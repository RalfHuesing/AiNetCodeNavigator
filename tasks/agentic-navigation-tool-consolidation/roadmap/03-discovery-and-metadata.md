# M3 — Discovery and metadata ownership

## Intent and scope

Improve declaration discovery and source-to-metadata transitions with exact ownership. Implements P3 and [concept 5.4–5.5](../concept.md#54-type-relationships-and-metadata-contracts). Depends on M2; ends with twelve public tools.

## Executable points

- [x] **M3.1 — Integrate extension declarations and discovery filters.** Extend `find_symbol` for source/assembly extensions, project/namespace/signature filters, and declared receiver matching. Preserve existing discovery/batching and old extension-search capability. Migrate regressions and consumers/docs; remove `find_assembly_extensions` after replacement checks pass. Acceptance: filtered results retain actual extension status, correct owners and usable references; ineffective/invalid argument combinations fail; no expression-applicability promise.
- [x] **M3.2 — Resolve metadata contracts in source type relationships.** Use existing loaded compilation/reference facts for qualified metadata types and exact member IDs, including explicit validated metadata-owner selection. Preserve source-first resolution and ambiguity semantics. Acceptance: BCL/interface-member implementations and overrides bind semantically; duplicate owners do not get guessed; returned source/assembly references support exact owner-qualified follow-ups; arbitrary DLL paths are not loaded by this selector.
  - [x] **M3.2a — Establish exact metadata resolution and owner evidence.** Reuse captured immutable reference facts and pass them through the request-lived source context. Resolve supported raw type/member identifiers across loaded compilations, retaining bound contract occurrences, proven path/image/declaration identities, ambiguity and validated owner selection. Verify these Core behaviors with small existing fixture builders; do not expose the incomplete MCP capability yet.
  - [x] **M3.2b — Integrate image-safe relationships and the MCP contract.** Use the validated occurrences for semantic hierarchy/implementations, including transitive source project relationships and event mappings, without merging distinct images with equal assembly identities. Complete source-first routing, root/implementation ownership, options/cursors/recovery, current documentation, targeted integration/extended checks and W5 Exploration follow-ups.
- [ ] **M3.R — Independent Sol review, fixes, and acceptance.** Review filter comparison behavior, source-first/metadata fallback, overload/owner mapping, assembly closure limitations, advertised follow-ups, and twelve-tool catalog. Close after required fixes/checks pass.
  - [x] **M3.C1 — Correct independent review findings.** Enumerate every selected construction of one generic metadata interface when mapping its member definition, preserving exact image proof and source handoffs. Restore useful assembly-extension recovery after the final domain page when missing references, rather than display limits, cause partial analysis. Prove both defects with small failing-before checks, run affected official gates, and obtain focused re-review.
