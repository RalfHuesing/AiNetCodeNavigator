Source inspection narrows the failure to adjacent XML files for referenced PE images, rather than loaded source comments. The capture owner already reads immutable XML bytes, hashes them and rebinds a byte-backed documentation provider. That provider returns literal member XML without resolving include files; navigation consumes declaration IDs, not expanded documentation prose. Requiring a captured external snippet therefore rejects an input the implementation does not consume.
