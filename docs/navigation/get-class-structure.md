# Get Class Structure

`ClassStructureScanner.ScanAsync` resolves a type or a member to its containing type using the [shared symbol resolution contract](symbol-resolution.md), then returns the type kind, declaring files, source line total, and a member list. Ambiguous names return structured errors with selectable resolution candidates. It includes declared fields, constants, events, properties, methods, and constructors across partial declarations. It reports declared accessibility separately from each member signature, omits compiler-generated members other than constructors, and includes invariant literal values for constants.

Type kinds distinguish `Class`, `Record Class`, `Record Struct`, `Interface`, `Struct`, and `Enum`. A record's positional primary-constructor parameters appear as `PrimaryCtor-Param` entries in addition to the record's declared members. Kind and name filters and `SortBy` apply before the `MaxMembers` limit. For `SortBy=lines` (the default), declarations sort by file path, declaration line, then name before the page. The MCP source route also applies `scopeType=all|production|tests` and `includeGenerated` before counts and paging; defaults are `all` and `false`. Public `maxMembers` is a page size from 1 through 200; every filtered member remains reachable through `resultCursor`. The JSON page repeats type/file totals and contains only that page's member entries and cursor. Analysis completeness stays separate from page availability.

Markdown output adds a `File` column for types declared in multiple files, showing each member's declaring file. Dynamic table cells escape pipe characters and replace line breaks with spaces so signatures stay in one table row.

Source members carry stable references when their declarations have a unique canonical identity. Compiler-generated constructors and synthetic record-parameter rows do not have references. A member reference resolves to that member's containing type for another class-structure query. A missing type returns `null`; an invalid, mismatched, absent, or ambiguous reference returns a payload with a recoverable error. Null requests or solutions and blank symbol identifiers throw argument exceptions. `RenderMarkdown` rejects a null payload with `ArgumentNullException`. See [Shared Symbol Resolution](symbol-resolution.md) for the reference contract.

The MCP host registers `get_class_structure` for source and managed-assembly targets. Assembly references resolve only against their selected target; callers retain the exact `targetPath` reported by discovery. Source and assembly handler contracts reconstruct member pages beyond the former 200-member display cap, then follow owner references. Outer response pages are reconstructed before reading the domain cursor. Source contracts cover generated-source inclusion, typed reference errors, and independent byte and token budgets. Assembly scope filters do not apply because assembly symbols come from the selected binary's compilation. See [MCP Host](../mcp-host.md).

Assembly `get_class_structure` responses include `decompiledSourceRoot`, the absolute physical source root for the acquired decompiler generation. Paths within this root in the `files` list and member `filePath` fields are relative to it; an unusual source document outside the root remains an absolute path. Every result-cursor page repeats the root so paths can be resolved without an earlier page. The assembly `targetPath` and stable member references continue to identify the DLL owner.

The result cursor is bound to the target, snapshot, symbol, source scope, filters, ordering, and `maxMembers` page size. Reusing it with a changed query or page size returns `RESULT_CURSOR_ARGUMENT_MISMATCH`; changed target contents return `STALE_SNAPSHOT`. Response byte and token budgets may change while reading outer response pages. Reconstruct all outer pages for one result before using its next `resultCursor`.
