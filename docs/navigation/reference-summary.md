# Reference summary

`find_references` accepts `includeSummary=false` for source and assembly targets. When enabled, `summary` aggregates the existing discovered traversal before display paging, without another symbol search. It reports `directReferenceSiteCount` (depth one), `deeperReferenceSiteCount` (depth greater than one), `totalReferenceSiteCount`, and `maxDepthReached` (zero for an empty set). These count reference sites, including non-call uses, rather than unique callers or runtime consequences.

`projects` and `files` are distinct owner-qualified identities, sorted by owner target, project identity, then project name or file path using ordinal comparison. `projectCount` and `fileCount` count these identities. Source identities retain the solution owner and canonical project path, so same-named projects and linked physical files in different projects remain distinct. A source project without a file path has a snapshot-local `project:` identity and no `projectPath`. Assembly identities retain the canonical DLL owner; generated decompilation project paths are not project identities. File identities include their owning project and the reported relative file path.

Every logical `resultCursor` page of an unchanged query and snapshot repeats the same summary. It is neither a page subtotal nor an accumulating total; clients must not sum summaries across pages. Large summaries use existing outer response pages. Read all outer pages before advancing a result cursor. `includeSummary`, scope, traversal options, and page size remain part of query identity; response byte/token budgets can change during continuation.

`analysisComplete` and `omissions` describe the discovered set's analysis limits, independently of display paging. Node/depth limits and assembly closure, traversal, owner, or unresolved-reference omissions remain visible in both the summary and navigation metadata. A selected assembly owner with partial decompilation/navigation adds `assemblyOwnerIncomplete`, including when `includeReferences=false`; its available sites remain usable and the same omission is reported without selecting a summary. A fully delivered summary can describe partial analysis. Increasing response budgets does not discover more sites. The reference route preserves its existing source filters, cancellation, snapshots, and assembly generation leases.
